# Landing page prototype

Static promotional prototype for Deshi Mula Extended.

## Preview

Serve the repository root so relative product assets resolve correctly:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173/prototypes/web/v1.html`.

You can also open `v1.html` directly from the filesystem.

The page uses the Tailwind CSS v4 browser CDN and has no landing-page build step. The browser CDN is suitable for this prototype; switch to a compiled Tailwind build before production deployment.
